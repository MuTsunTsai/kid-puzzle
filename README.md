# 幼兒益智遊戲

一款專為幼兒設計的益智遊戲集，使用 Flutter 開發，主要目標平台為 Android，
同時支援 Web 與 iOS。

目前第一個遊戲模式為**拼圖**，未來會陸續加入更多益智遊戲模式
（如配對、找不同等）。

## 拼圖模式功能

- **塊數可調**：支援 2~30 塊，可在家長設定中指定範圍，每關隨機落在範圍內。
- **兩種切割模式**：
	- **網格切割**：標準的 C 行 × R 列網格，並可隨機在某一列或某一行多切一刀
	  製造變化。
	- **不規則切割**：基於 Voronoi 圖 + Delaunay 三角化的演算法，可產生包含凹
	  多邊形的不規則拼片，且共用邊以 C1 連續的曲線過渡，視覺上更加自然。
- **直覺互動**：
	- 拖曳鄰近的拼片會自動融合成群組，群組可整體拖曳。
	- 拼片靠近正確位置時會自動鎖定。
	- 支援多指同時拖曳多片拼圖。
	- 旋轉模式可雙指旋轉拼片（額外挑戰）。
- **動畫與音效**：進場切割線浮現、拼片飛散、吸附回饋、過關慶祝；搭配音效與
  預錄的中文語音鼓勵。
- **家長區**：
	- 首頁右上齒輪需長按 3 秒並通過加法題才能進入，避免幼兒誤觸。
	- 可調整塊數範圍、切割模式、提示線、音效與語音開關。
	- Android 平台可選擇進入拼圖時鎖定畫面，避免幼兒誤觸系統列。
- **圖庫**（規劃中）：除內建圖之外，家長可匯入自訂照片，並以 4:3 比例裁切。

## 開發

```sh
flutter pub get
flutter run            # 啟動開發版本
flutter test           # 執行單元測試
flutter analyze        # 靜態檢查
flutter build apk      # 建置 Android release apk
flutter build web --base-href /kid-puzzle/   # 建置 Web 版（GitHub Pages）
```

Web 版本透過 GitHub Actions 自動部署至
<https://mutsuntsai.github.io/kid-puzzle/>。
